# Seguridad en Sistemas Informáticos — Tema 1.2

Transparencias (Beamer/LaTeX, 16:9) del **Tema 1.2: Introducción a la Seguridad
Informática y de la Información** de *Seguridad en Sistemas Informáticos* (UCLM).

## Contenido
- `presentacion_1.2.tex` — fuente LaTeX (Beamer, plantilla del centro).
- `beamertemplate.sty` — plantilla (base *Madrid*, paleta azul marino).
- `img/` — imágenes y diagramas del tema.
- `presentacion_1.2.pdf` — presentación compilada.

> Convertido (texto + imágenes) desde el `.pptx` original. Algunos títulos y encuadres
> pueden requerir un retoque manual fino.

## Compilar
```bash
latexmk -pdf presentacion_1.2.tex
```
